# 来源层

`raw/sources/**` 是 AI Wiki 的统一、不可变来源层。目录结构镜像迁移前的仓库根目录，例如原 `docs/**`、`openclaw/**` 和根目录文档分别进入 `raw/sources/docs/**`、`raw/sources/openclaw/**` 与 `raw/sources/`。迁移只改变存放位置，不改写或丢弃用户原文。

`wiki/**` 是主题化知识层。知识页可以合并多个来源、拆分概念并增加导航，但必须在 frontmatter 的 `sources` 中使用从页面位置可解析的相对路径，逐项指向 `raw/sources/**` 中的真实文件。完整聚合关系见 [来源目录](SOURCES.md)。

## 更新规则

1. 新原文先按其原始路径加入 `raw/sources/**`，保持内容和文件名可追溯。
2. 原文需要更新时，保留可核对的变更记录，不以知识页反向覆盖来源文件。
3. 来源新增或发生实质变化后，定位 `sources` 引用它的专题页，刷新结论、状态和 `updated` 日期。
4. 专题页的合并、拆分或重命名必须同步更新导航与 [来源目录](SOURCES.md)，不得让来源引用失效。
